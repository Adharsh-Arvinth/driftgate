# Claim Element Mapping Matrix: DriftGate

This document maps every element of the candidate patent claims directly to the implemented source code modules, their technical purpose, prior art overlap, and differentiating novelty evidence.

---

| Claim Element | Implemented In | Technical Purpose | Prior Art Overlap | Distinguishing Novelty Feature | Evidence / Source Code |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Claim 1(a): Global Model Reception** | `src/client.py` (`set_model_params`) | Synchronizes edge client local network weights with central server. | Universal to all FL (FedAvg, McMahan 2017). | Standard baseline operation. | `client.py` (`set_model_params`) |
| **Claim 1(b): Local Concept Drift Detection** | `src/drift_detector.py` (`EnsembleDriftDetector`) | Identifies statistical deviations in streaming sensor data distributions. | Known in FedDrift (2023), FedDriftGuard (2026), FL-MalDrift (2025). | Combines loss ADWIN, Page-Hinkley, and DDM error rates into voting ensemble. | `drift_detector.py` (`EnsembleDriftDetector`) |
| **Claim 1(c): Transience vs. Persistence Classification** | `src/drift_detector.py` (`TransienceClassifier`) | Differentiates temporary sensor glitches from sustained distribution shifts using a multi-round verification window. | **NONE.** Prior art treats all detected drift identically or uses global clustering. | Temporal persistence window $\tau_{wait}$ evaluates post-alarm revert rates before triggering transmission modes. | `drift_detector.py` (`TransienceClassifier`) |
| **Claim 1(d-1): Client FSM Transmission Gating** | `src/state_manager.py` (`ClientFSM`, `FederationStateManager`) | Formally governs client lifecycle states (STABLE, DRIFTING, TRANSIENT, PERSISTENT, ADAPTING, ELIGIBLE). | Procedural workflow FSMs exist (FLaMAS, IBM US11588621), but not for drift lifecycle. | Direct coupling between transience classification and radio transmission suppression (0 bytes uplink). | `state_manager.py` (`ClientFSM`) |
| **Claim 1(d-2): Layer-Divergence Selective Transmission** | `src/communication_controller.py`, `src/drift_detector.py` (`LayerDivergenceTracker`) | Identifies specific network layers affected by drift and transmits only diverging partitions. | Generic sparsification is known; layer-selective FL exists in split learning, but not gated by drift divergence. | Ratio of layer gradient norm to baseline tracks drift impact; transmits only drifted layers (e.g., classification head), keeping base invariant. | `communication_controller.py` (`prepare_update`), `drift_detector.py` (`LayerDivergenceTracker`) |
| **Claim 1(e): Joint Client Selection Scoring** | `src/client_selector.py` (`DriftGateSelector`) | Prioritizes clients based on state, drift severity, reliability, and bandwidth efficiency. | Oort uses loss utility; FedDrift uses cluster membership. | Multi-signal scoring combining FSM state gating with gradient reliability and selective bandwidth savings. | `client_selector.py` (`DriftGateSelector.score_client`) |
| **Claim 1(f): Multi-Episode Memory Aggregation** | `src/episode_memory.py` (`DriftEpisodeManager`), `src/aggregation.py` (`AggregationEngine`) | Modulates server aggregation coefficients based on historic resolution quality across past drift episodes. | DTAFA/FedRGEA use instantaneous reliability; FedAvg uses sample size $n_k$. | Structured episode registry tracks historical multi-round recovery trajectories with recurrence penalties. | `episode_memory.py` (`DriftEpisodeManager`), `aggregation.py` (`AggregationEngine`) |
| **Claim 8: Post-Drift Adapting & Recovery Verification** | `src/state_manager.py`, `src/aggregation.py` | Governs controlled re-entry of recovered clients via head-only verification before granting eligible status. | Continuous continual learning without discrete verification gates. | Client transitions from ADAPTING to ELIGIBLE only after local accuracy meets $\alpha_{recov}$ threshold. | `state_manager.py` (`ClientFSM.update`) |
| **Claim 10: Client Update Reliability** | `src/reliability_engine.py` (`ClientReliabilityEngine`) | Tracks coefficient of variation of gradient norms, non-suppression rate, and accuracy stability. | Reputation tracking in blockchain FL. | Direct physical gradient norm stability coupled into federated aggregation weights. | `reliability_engine.py` (`ClientReliabilityEngine.get_reliability`) |
| **Claim 13: Top-k Parameter Compression** | `src/compression.py` (`topk_sparsify`, `quantize_params`) | Prunes low-magnitude gradient coordinates for additional bandwidth reduction. | Standalone gradient compression. | Integrated on top of layer-selective subsets with rigorous byte accounting. | `compression.py` (`topk_sparsify`) |
